Premier essai local

Le README donne les commandes PowerShell pour démarrer le serveur de découverte sur une base neuve, avec le moteur factice existant. On peut envoyer, corriger, rappeler un passage, inspecter le contexte puis retrouver le journal.

Les réponses « Réponse factice » servent à observer ce parcours. Le serveur de l’application et l’activation volontaire d’un modèle Ollama sont présentés dans une section distincte. L’essai ne migre pas les conversations existantes.

L’usage reste local, pour un utilisateur et un processus. La suppression volontaire et les sauvegardes restent des étapes du contrat P6. Le guide du dialogue conserve les preuves et le contre-exemple d’emploi d’un rappel corrigé avec Gemma.

Où sont les preuves ?

Sources, tests, protocoles et guides sont versionnés. Les traces data/runs/ et les exports output/ restent locaux ; les liens vers ces pièces dans les notes ne sont pas des téléchargements publics.
